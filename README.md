# Convertisseur de devises

Petite application de bureau en Python pour convertir des montants entre différentes devises, avec une interface sombre réalisée en PySide6.

## Fonctionnalités

- Conversion en temps réel entre plus de 40 devises
- Bouton pour inverser les devises
- Interface sombre et épurée

## Installation

```bash
pip install -r requirements.txt
python main.py
```

## Technologies

- Python 3
- PySide6 (Qt)
- CurrencyConverter (taux de la BCE)
